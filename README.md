# Лабораторная работа №4

Вариант 12. Страница анализирует время автономной работы набора гаджетов.

Скрипт находит максимальное и среднее время, сумму значений, устройства с автономностью больше 8 часов и долю устройств, работающих не больше 4 часов.

Для запуска нужно открыть `index.html` в браузере.
